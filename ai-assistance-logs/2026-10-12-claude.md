QDVC Response Letter is a macOS (Swift) application that helps an author write a typical response letter for a journal paper resubmission.

As you may be aware, when you send in a journal paper and you're granted a revision, you get a decision letter (for the purposes of this app, assume it is formatted as plain text) which typically contains comments from a combination of [senior editor AND/OR associate editor AND/OR special issue editor AND/OR department editor AND/OR track chair] and then the comments from the reviewers (reviewer 1, reviewer 2, reviewer 3, etc.)

It is then necessary to write a response letter responding to each of the comments, one at a time. It is at the author's discretion how the comments are itemised. Once they are itemised, they are typically given ID numbers (e.g., SE-01, SE-02, SE-03; AE-01, AE-02, AE-03; RE1-01, RE1-02, RE1-03; etc.) and the author needs to write a response each of them.

The app should enable the user to:

* Create a new response document, starting by pasting the decision letter.
* Deconstruct the response document into appropriate 'comments' by highlighting the comment text, then enumerating all the demarcated comments.
* Triage the comments by marking each comment in a colour (typically green = easy to address, yellow = a little bit trickier, red = requires thorough consideration, needs in-depth discussion with coauthors) and entering dot-points of the initial ideas for a response.
* Tag comments as being related (e.g., comment AE-03 is summarising RE1-07 and RE2-05).
* Draft comment responses. Each response may contain:
   * Free-flowing text
   * A text label which is re-used across multiple comments (e.g., a page reference, section reference, verbatim quote, number of data points, etc.). The user should be able to see the list of all of these and make changes that cascade to all instances. (Please help me come up with a better terminology for this concept...)
